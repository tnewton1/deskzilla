## Apple Silicon fork

Native Apple Silicon macOS support and related compatibility work in this fork
were added and are maintained by **Travis Newton** beginning in 2026.

Fork-specific work includes:

- native arm64/aarch64 Java 8 build and runtime support;
- a self-contained macOS `Deskzilla.app` bundle;
- Apple Silicon `sqlite4java` native library support;
- compatibility with modern SQLite `PRAGMA index_list` results;
- macOS application icon packaging and source persistence;
- Apple Silicon build automation and documentation; and
- packaging changes needed to run Deskzilla natively on current Apple Silicon
  Macs.
